# 金融基础设施时间线考据（Financial Infra Timeline）

为小说查证**交易所、券商、金融品种、制度**的「哪年才有」——金融题材最致命的穿帮是**历史偏差**：写了当时还不存在的交易所/品种/制度。

## When to Use

- 小说写到主角「在某交易所交易 / 开某券商账户 / 交易某品种 / 用某制度」；
- 需要核验「某交易所/券商/品种/制度，故事年份有了吗」；
- 数字货币、股票、期货、衍生品等金融场景的年代考据。

## 核心原则

**金融基础设施有强烈的时间性**：交易所会倒闭、券商会合并、品种会上市、制度会开通。写某年剧情前，必须先查「这个机构/品种/制度，那年有了吗、还在吗」。

## 券商（2013 年已有，老牌）

- 中信证券（1995）、华泰证券（1991）、国泰君安（1999 合并）等老牌券商 2013 年都存在。
- 但注意：券商**业务/牌照**有时间性（如某业务某年才获批），写具体业务前再核。

## 查证入口

- 数字货币交易所成立时间：维基百科、bitcointalk 官方公告帖、当年媒体报道
- A 股制度开通时间：上交所/深交所官网公告、证监会官网、中新网/证券时报当年报道
- 券商成立/业务：中国证券业协会、券商官网

## 时间性验证方法

写金融场景前，问三句：
1. **这个交易所/券商，故事年份成立了吗？倒闭了吗？**（币安 2017 才成立、Mt.Gox 2014 就倒闭）
2. **这个品种，故事年份上市了吗？**（以太坊 2015、BCH 2017）
3. **这个制度/业务，故事年份开通了吗？**（沪港通 2014、科创板 2019）

拿不准就查，查不到就模糊化（写「一家老牌券商」不写「某具体券商」），**绝不写当时不存在的机构/品种**。

## 验收

- 每个金融实体落到「名称 + 成立/开通年份」；年份 × 故事年份匹配；
- 关键时间点有来源；「待核验」的写前必核；
- 查不到就模糊化，绝不编交易所/券商/品种。
