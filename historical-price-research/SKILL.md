# 历史价格/行情考据

为年代设定（尤其中国 2010 年代）查证真实物价、行情、车型、地理事实。服务于小说章节、事实核查、回忆类写作。

## When to Use

- 小说/剧本需要某一历史年份的具体物价、油价、车价、工资、房价、烟酒价格；
- 需要核验"当年 XX 多少钱"这类回忆性说法；
- 需要给作者提供"事实+来源+可信度"格式的资料包，且明确区分已验证/待核验/推演/未查到。

## 输出纪律（每条必带）

每条资料 = **事实内容 + 来源 URL + 验证状态**，状态四选一：
- **verified**：多源交叉或 API 直连原始数据（搜索摘要级核验要注明）
- **待核验**：单一来源/来源不够权威
- **推演**：由 verified 数据合理推算，必须写明锚点（"由哪条数据推出"）
- **未查到**：明确标出，并附"给作者的安全写法"建议，绝不编数字

## 技法库

### 中国油价等"调价新闻算术"

官方定价品（油价等）有精确调整记录：**调后价 − 涨幅 = 调前价**。
例：某市 2013-02-25"粤Ⅳ 93 号涨 0.24 元至 8.09 元/升"→ 2013 年 1 月执行价 = 7.85 元/升。

- 可靠当年报道源：本地宝（m.*.bendibao.com）、中新网（chinanews.com.cn）、新浪财经、百度文库价格变动表。
- 注意油品标准时间线：多省 2013 年前后从 93/97 号（国Ⅲ）逐步切换 92/95 号（国Ⅳ），同一年不同城市/标准价格不同，务必匹配故事年份+地点。

### 加密货币历史价格

- **CoinGecko 公开 API 不可用于老数据**：`market_chart` 的 from/to+interval 形式会报 `Missing parameter days`；勿在 CoinGecko 上浪费时间。
- **blockchain.info 全史 API 可用**（2010 年至今，USD 日价）：
  `curl "https://api.blockchain.info/charts/market-price?start=2013-01-01&end=2013-01-10&format=json"`
  返回 Unix 时间戳 + 日均价；这是最硬的原始数据源（Python 用 urllib+json 拉全段再逐日打印成表即可，实测可一次拉半年）。
- **注意：blockchain.info 是跨交易所"日均价"，不是日内极值**。小说场景要"崩盘夜屏幕数字"时，日内峰值/低点必须从**当时新闻**找：检索 `bitcoin magazine <年份> <事件名>`、`ibtimes <年份> bitcoin` 等当年报道，它们当天/隔天就记录了精确日内数字和交易所暂停交易等事件；两个口径（日均价 vs 交易所日内价）不要混用，交叉验证时写明各自口径。
- 人民币折算：当年汇率无直接来源时标"推演"，或用 novel-era-data 的汇率脚本查官方参考价。

### 车辆数据

- 油耗：小熊油耗 xiaoxiongyouhao.com 车主众测均值 + 样本量；汽车之家论坛有市区/高速/堵车分场景实测。
- 通病：汽车之家论坛帖，多家互证。
- 新车当年价：凤凰网/搜狐上市新闻（含指导价区间），比参数站可靠。
- 二手当年行情：当年精确价几乎查不到。技法：现在行情 + 车龄线性反推，必须标"推演"。

### 中国地理/官方事实

- 百度百科条目 + 政府门户（*.gov.cn）交叉核验距离/行政归属。
- 警惕"里/公里"笔误（如官网"距市区 15 里"实为 15 公里）；距离类事实给区间（14~15 公里）。

### 中国历史网络资料检索（2010 年代题材）

- **SEO 垃圾站污染严重**：搜"2013 某地 租金"这类词，前排常是站群/采集站/无关结果。对策：搜索词带**年份+具体地点+具体名词**，或直接找当年媒体原文标题。
- **当年媒体原文比百科可靠**：中新网/中国证券报等当年报道常被多个地方站全文镜像转载；原站反爬或只返回几 KB 空壳时，换镜像站抓取。
- **旧站编码**：2010 年代地方站常是 GBK/GB18030，curl 抓回乱码时按 utf-8→gbk→gb18030 依次尝试解码（Python `raw.decode(enc)` 循环）。
- **中文维基百科（zh.wikipedia.org）可用 curl 直接抓**，时间线类条目的逐日细节比搜索摘要全；英文版 History of bitcoin 类条目也含关键数字。
- **精确历史数字查不到是常态**：给出"官方宏观锚点 + 近年价格倒推"的推演区间并明确标注锚点，正文建议模糊化写法，绝不硬编。

### 页面抓取被拦的回退

web_extract 对部分域名报 "Blocked: URL targets a private or internal network address"（SSRF 防护误判）时：
1. **不要反复重试同一路径**；
2. 搜索结果的摘要本身常已含关键数字；
3. 需要原始数据时用 curl 直接打 API/静态接口；
4. 仍不行的，用 scrapling skill（HTTP/动态/stealth 三种抓取）兜底。

## 验收

- 关键事实有来源 URL 与日期；年份 × 地域匹配；
- 事实/推演/建议分栏；所有无来源数字标"未查到"或"推演"。

## 事实库说明

- 本 skill 可为具体作品建立「章节级考据库」（存于 `references/` 目录），续写同作品同章节先查，勿重复考据。
- 章节级考据库含具体作品的地名/价格/角色，属作品专属，**不同步公开仓库**（如需同步请先脱敏）。
