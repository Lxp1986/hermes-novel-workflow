# Hermes 小说创作工作流（Novel Workflow）

一套宿主无关的 AI 小说创作工作流：从「几个角色包 + 开头 + 结局」出发，通过分阶段结构化提问定制小说框架，冻结后逐章创作，并对每个现实细节做「查证 + 时间性 + 匹配一致性」三重校验，确保出品经得起专业读者推敲——让人怀疑「这是不是把真实的事写成了小说」。

## 核心理念

> **谎话不能有一丁点破绽。** 虚构故事就像说谎——可以说，但不能有破绽，否则「知道的人」一眼看穿。

- **虚构层**（角色、情节、对话、心理）自由编。
- **现实层**（地名、物价、历史事件、商品特性、物理规律、法律）必须真实，绝不编造。
- 查不到 → 模糊化 / 替换同类真实，绝不硬编。

## 工作流组成

| Skill | 职责 |
|---|---|
| `novel-foundation` | 立项（七阶段提问）+ 框架文件（00–06）+ 逐章 SOP + 现实细节验证系统 |
| `novel-site-publish` | 章节 → Hexo + GitHub Pages 博客站点发布 |

## 现实细节验证系统（核心）

三个维度，层层把关：

1. **细节四分法**：硬事实 / 地方事实 / 不可验证 / 纯虚构，分类处理。
2. **时间性验证**：这东西「故事发生的年份」有了吗？（高速路网、车型、App、政策都有「哪年才有」）
3. **匹配一致性验证**：物理/工程/常识自洽（涡轮车加低标号油、手枪几十发不换弹、350 公里 1 小时到——都是穿帮）。

外加「深挖方法」（查地方事实要搜最小行政单位词条，别泛搜大词）+「数据台账」（每条细节带 URL + 引句 + 日期，可追溯）。

## 宿主无关

纯 Markdown + 提问流程，任何 LLM agent（Hermes / Codex / 其他）加载即可跑。查证依赖宿主提供联网检索能力（任何等价工具皆可）。
